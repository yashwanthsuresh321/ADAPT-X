# Phase 1.7: Security Monitoring & Investigation Interface

## Overview
Phase 1.7 introduces a Next.js-based Security Operations Center (SOC) dashboard that allows security analysts to investigate alerts generated by the Detection Engine. This dashboard serves as the visualization and investigation layer of the ADAPT-X pipeline.

## Features
1. **Overview Dashboard**: High-level statistics on alerts, severity distributions, and threat intelligence.
2. **Alert Queue**: Paginated and filterable list of all security alerts generated by the ML and Detection engines.
3. **Investigation View**: Detailed breakdown of a specific alert, including:
   - Primary detection logic and AI/ML correlation probability.
   - Captured behavioral evidence.
   - The chronological sequence of raw telemetry events that led to the alert.
4. **Telemetry Explorer**: Interface to explore the raw and normalized events collected by Phase 1.3.

## Architecture
- **Framework**: Next.js 15 (App Router, Tailwind CSS, shadcn/ui).
- **Backend API**: Next.js API Routes connecting directly to the central PostgreSQL database.
- **Network**: Deployed in the `adaptx_network` at IP `10.10.10.100` and exposed to the host at `http://localhost:3000`.

## Verification
Phase 1.7 has been verified via `scripts/verify_lab.py`, ensuring:
- The Next.js container operates correctly on `10.10.10.100`.
- The Next.js Health API can establish a database connection.
- All API routes (Alerts, Statistics, Telemetry) respond successfully.

## Security Considerations
- Read-Only access to telemetry and features.
- Parametrized SQL queries are used via the `pg` driver to prevent SQL injection.
- The dashboard is restricted to the internal lab network but exposed exclusively for analyst review.
